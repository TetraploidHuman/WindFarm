# 挑战杯申报书 —— 需修改部分

## 最终数据源：corridor 合成风场实验

`runs/corridor/` — 中间强逆风带 + 南北顺风走廊的合成场景。
XGBoost 模型，50 trees，4,000 训练样本，120 步任务。

**最终指标**：

| 指标 | 数值 |
|------|------|
| 风速 RMSE | 5.337 → 0.717 m/s（降低 **86.6%**）|
| 垂直风 MAE | 0.491 → 0.170 m/s（降低 **65.4%**）|
| 风向 MAE | — |
| 模型 | XGBoost, 50 estimators, max_depth=3 |
| 训练样本 | 4,000（从 6,000 中采样）|

**路径指标**：

| 指标 | 数值 |
|------|------|
| 直线距离 | 33.0 格 |
| 实际路径 | 32.3 格（-2.1%）|
| 直线能耗（水平飞行）| 46,741 J |
| 实际能耗（水平飞行）| 45,499 J |
| 能耗节省 | +2.7% |
| 剩余电量 | 92.3% |

> 注：路径几乎直线（比例 0.979x），因走廊风场景中南北顺风区速度差异不足以驱动大幅绕行。2.7% 能耗节省虽小，但验证了系统在"不必要时不绕路"的合理性。
